# Zotero-Cat v0.3.1

[English](https://github.com/Zotero-Cat/Zotero-Cat/blob/main/doc/release-notes/0.3.1.md) | [中文](https://github.com/Zotero-Cat/Zotero-Cat/blob/main/doc/release-notes/0.3.1.zh-CN.md)

Zotero-Cat 是一个 Zotero 条目面板 AI 助手，用于阅读、总结、审阅和讨论文献条目，模型提供方由用户选择。

## 下载

从下方资源下载 `zotero-cat-v0.3.1.xpi`，在 Zotero 的 Add-ons Manager 中安装。

快速开始：

1. 下载 `zotero-cat-v0.3.1.xpi`。
2. 打开 Zotero。
3. 进入 `Tools -> Plugins`。
4. 安装 XPI 文件。
5. 在 Zotero-Cat 设置中配置 OpenAI-compatible 提供方。

## 兼容性

- 已支持：Zotero 9.x
- 尚未声明：Zotero 10 beta

Zotero 10 兼容性将在当前 Zotero beta 线通过人工 UI 清单后声明。

## 修复

这个补丁版本修复 `v0.3.0` 之后发现的 PDF 引文匹配回归：

- GLM 风格截断引文在省略号后跟闭合引号或句末标点时，也会继续进入 fallback。
- 模型输出里的断行连字符空格形态（例如 `fine- tuning`）会作为 PDF 行内复合词（例如 `fine-tuning`）的候选。
- 原有的 PDF 换行断词去连字符匹配路径保持不变。

## 升级说明

从 `v0.3.0` 升级只需安装新的 XPI。已有设置和本地会话历史会保留。

PDF 工具仍为实验功能，默认关闭。

## 已知限制

- PDF 工具仍是实验功能，默认关闭。
- 高亮/下划线文本必须是单个 PDF 页面内连续出现的原文；跨页高亮需要拆成每页一条提议。
- 扫描件、加密 PDF 或 OCR 质量较差的 PDF 可能无法提供可靠可抽取文本。
- 尚未开启 Zotero 10 beta 支持。

## 非隶属声明

Zotero-Cat 是独立项目，不隶属于 Zotero。
