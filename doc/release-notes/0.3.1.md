# Zotero-Cat v0.3.1

[English](./0.3.1.md) | [中文](./0.3.1.zh-CN.md)

Zotero-Cat is a Zotero item-pane AI assistant for reading, summarizing,
reviewing, and discussing research items with user-selected model providers.

## Download

Download `zotero-cat-v0.3.1.xpi` from the assets below and install it from
Zotero's Add-ons Manager.

Quick start:

1. Download `zotero-cat-v0.3.1.xpi`.
2. Open Zotero.
3. Go to `Tools -> Plugins`.
4. Install the XPI file.
5. Configure an OpenAI-compatible provider in Zotero-Cat settings.

## Compatibility

- Supported: Zotero 9.x
- Not yet declared: Zotero 10 beta

Zotero 10 compatibility will be declared only after the current Zotero beta line
passes the manual UI checklist.

## Fixes

This patch release fixes PDF quote matching regressions found after `v0.3.0`:

- GLM-style truncated quotes still fall back when the trailing ellipsis is
  followed by closing quotes or sentence punctuation.
- Model-emitted line-break hyphen spacing such as `fine- tuning` is treated as
  an alternate for inline PDF compounds such as `fine-tuning`.
- The existing dehyphenated PDF line-break matching path remains intact.

## Upgrade Notes

Upgrade from `v0.3.0` by installing the new XPI. Existing settings and local
conversation history are preserved.

PDF tools remain experimental and off by default.

## Known Limitations

- PDF tools are experimental and off by default.
- Highlight and underline text must be a continuous verbatim span from one PDF
  page; cross-page highlights need separate proposals per page.
- Scanned, encrypted, or OCR-poor PDFs may not provide reliable extractable
  text.
- Zotero 10 beta support is not enabled yet.

## Non-affiliation
