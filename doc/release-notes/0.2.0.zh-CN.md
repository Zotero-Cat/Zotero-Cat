# Zotero-Cat v0.2.0

[English](./0.2.0.md) | [中文](./0.2.0.zh-CN.md)

Zotero-Cat 是一个 Zotero 条目面板 AI 助手，用于阅读、总结、审阅和讨论文献条目，模型提供方由用户选择。

## 下载

从下方资源下载 `zotero-cat-v0.2.0.xpi`，在 Zotero 的 Add-ons Manager 中安装。

快速开始：

1. 下载 `zotero-cat-v0.2.0.xpi`。
2. 打开 Zotero。
3. 进入 `Tools -> Plugins`。
4. 安装 XPI 文件。
5. 在 Zotero-Cat 设置中配置 OpenAI-compatible 提供方。

## 兼容性

- 已支持：Zotero 9.x
- 尚未声明：Zotero 10 beta

Zotero 10 兼容性将在当前 Zotero beta 线通过人工 UI 清单后声明。

## 亮点

本版本加入第一版实验性 PDF 工具里程碑。PDF 工具默认关闭，需要在聊天控制区手动开启。

- 面向当前 Zotero 条目的 `read_pdf` 和 `list_annotations` 读取工具。
- 支持高亮、批注、修改和删除操作的可审阅标注提议卡片。
- PDF 写入前必须经过 Accept / Reject / Accept All / Reject All 确认。
- 支持按当前会话和附件范围生效的同类标注操作“总是允许”。
- PDF 高亮定位使用 PDF 用户坐标，并按单页内文本匹配。
- quote 定位失败时进入修复提示，不生成猜测位置的高亮。
- 会话历史现在写入 Zotero 数据目录下的本地 JSON 文件，不再写入大型 preference payload。
- 工具调用展示和执行拆成两条管道，provider 流式响应收尾较慢时也能继续执行已识别的工具 action。

## 升级说明

从 `v0.1.2` 升级只需安装新的 XPI。已有设置会保留。旧 preference 中的会话历史会迁移到：

```text
<Zotero data directory>/zotero-cat/agent-conversations.json
```

PDF 工具仍为实验功能。如果只需要早期版本的聊天、上下文和联网搜索能力，可以保持关闭。

## 隐私

Zotero-Cat 将设置和自定义上下文本地保存在 Zotero preferences 中，会话历史写入本地 JSON 文件，API Key 保存在 Firefox Login Manager 中。内容仅发送给用户配置的模型提供方和可选搜索服务。

参见：

- [Privacy](https://github.com/Zotero-Cat/Zotero-Cat/blob/main/doc/PRIVACY.md)
- [隐私说明](https://github.com/Zotero-Cat/Zotero-Cat/blob/main/doc/PRIVACY.zh-CN.md)

## 已知限制

- PDF 工具仍是实验功能，默认关闭。
- 高亮/下划线文本必须是单个 PDF 页面内连续出现的原文；跨页高亮需要拆成每页一条提议。
- 扫描件、加密 PDF 或 OCR 质量较差的 PDF 可能无法提供可靠可抽取文本。
- 联网搜索目前仅使用搜索片段，不抓取整页内容。
- Token 预算为估算值。
- 模型上下文长度和 reasoning-effort 选项取决于提供方返回的元数据。
- 尚未开启 Zotero 10 beta 支持。

## 非隶属声明

Zotero-Cat 是独立项目，不隶属于 Zotero。
