# Zotero-Cat v0.3.0

[English](https://github.com/Zotero-Cat/Zotero-Cat/blob/main/doc/release-notes/0.3.0.md) | [中文](https://github.com/Zotero-Cat/Zotero-Cat/blob/main/doc/release-notes/0.3.0.zh-CN.md)

Zotero-Cat 是一个 Zotero 条目面板 AI 助手，用于阅读、总结、审阅和讨论文献条目，模型提供方由用户选择。

## 下载

从下方资源下载 `zotero-cat-v0.3.0.xpi`，在 Zotero 的 Add-ons Manager 中安装。

快速开始：

1. 下载 `zotero-cat-v0.3.0.xpi`。
2. 打开 Zotero。
3. 进入 `Tools -> Plugins`。
4. 安装 XPI 文件。
5. 在 Zotero-Cat 设置中配置 OpenAI-compatible 提供方。

## 兼容性

- 已支持：Zotero 9.x
- 尚未声明：Zotero 10 beta

Zotero 10 兼容性将在当前 Zotero beta 线通过人工 UI 清单后声明。

## 亮点

本版本聚焦 provider / 工具调用可靠性和 PDF 工具加固。

- 原生 `tool_calls` 回合现在会在当前会话里保存匹配的 `role: "tool"` 消息，避免严格 provider 因孤儿工具调用历史拒绝下一轮请求。
- Function Calling 处理更规范：`reasoning_content` 回传、原生工具不支持 fallback 等 provider quirks 统一按 endpoint 记录，请求消息 shape 集中在一个模块里处理，单回合 runner 会先完成已知 quirk 自恢复，再把控制权交回 Zotero UI / 工具循环。
- 工具定义现在遵循轻量 MCP / OpenAI-compatible schema 契约，已注册工具可以一致导出 function specs；实际执行和人工确认仍由 Zotero-Cat 持有。
- 工具输出和用户可见文本分成不同运行路径；长时间联网搜索、PDF 读取、标注准备和标注写入都会显示同一条行内活动状态。
- PDF 高亮/下划线匹配能处理更多真实模型引文，包括省略号截断、长引文后半句非逐字原文、换行断词、Unicode 连字符，以及 `cannot` / `can not` 差异。
- 联网搜索默认不再只返回 5 条结果，工具输入可以使用 `maxResults`、`count` 或 `limit` 请求更多结果。
- 开启 PDF 工具时，聊天控件移除了手动上下文注入开关，使 PDF 流程优先通过工具读取，而不是优先预注入 prompt。
- agent UI/runtime 重构后，`section.ts` 降到约 935 行，工具链、UI 渲染、模型元数据和 provider 辅助逻辑被拆到更小模块。

## 升级说明

从 `v0.2.0` 升级只需安装新的 XPI。已有设置和本地会话历史会保留。

PDF 工具仍为实验功能，默认关闭。

## 隐私

Zotero-Cat 将设置和自定义上下文本地保存在 Zotero preferences 中，会话历史写入本地 JSON 文件，API Key 保存在 Firefox Login Manager 中。内容仅发送给用户配置的模型提供方和可选搜索服务。

参见：

- [Privacy](https://github.com/Zotero-Cat/Zotero-Cat/blob/main/doc/PRIVACY.md)
- [隐私说明](https://github.com/Zotero-Cat/Zotero-Cat/blob/main/doc/PRIVACY.zh-CN.md)

## 已知限制

- PDF 工具仍是实验功能，默认关闭。
- 高亮/下划线文本必须是单个 PDF 页面内连续出现的原文；跨页高亮需要拆成每页一条提议。
- 扫描件、加密 PDF 或 OCR 质量较差的 PDF 可能无法提供可靠可抽取文本。
- 联网搜索目前仅使用搜索片段，不抓取整页内容。
- Token 预算为估算值。
- 模型上下文长度和 reasoning-effort 选项取决于提供方返回的元数据。
- 尚未开启 Zotero 10 beta 支持。

## 非隶属声明

Zotero-Cat 是独立项目，不隶属于 Zotero。
