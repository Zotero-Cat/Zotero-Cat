# Zotero-Cat v0.2.0

[English](https://github.com/Zotero-Cat/Zotero-Cat/blob/main/doc/release/notes/0.2.0.md) | [中文](https://github.com/Zotero-Cat/Zotero-Cat/blob/main/doc/release/notes/0.2.0.zh-CN.md)

Zotero-Cat is a Zotero item-pane AI assistant for reading, summarizing,
reviewing, and discussing research items with user-selected model providers.

## Download

Download `zotero-cat-v0.2.0.xpi` from the assets below and install it from
Zotero's Add-ons Manager.

Quick start:

1. Download `zotero-cat-v0.2.0.xpi`.
2. Open Zotero.
3. Go to `Tools -> Plugins`.
4. Install the XPI file.
5. Configure an OpenAI-compatible provider in Zotero-Cat settings.

## Compatibility

- Supported: Zotero 9.x
- Not yet declared: Zotero 10 beta

Zotero 10 compatibility will be declared only after the current Zotero beta line
passes the manual UI checklist.

## Highlights

This release adds the first experimental PDF-tool milestone. PDF tools are off
by default and must be enabled from the chat controls.

- `read_pdf` and `list_annotations` read tools for the current Zotero item.
- Reviewable annotation proposal cards for highlight, note, update, and delete
  operations.
- Accept / Reject / Accept All / Reject All confirmation before PDF writes are
  applied.
- Optional conversation-scoped "Always allow" handling for matching annotation
  operations.
- PDF highlight placement uses PDF user coordinates and page-local text
  matching.
- Failed quote-location proposals trigger repair guidance instead of guessed
  highlight positions.
- Conversation history is now stored in a local JSON file under Zotero's data
  directory instead of large preference payloads.
- Tool-call display and execution are split so recognized tool actions can
  proceed even when a provider stream is slow to finish.

## Upgrade Notes

Upgrade from `v0.1.2` by installing the new XPI. Existing settings are preserved.
Conversation history stored in the older preference is migrated to:

```text
<Zotero data directory>/zotero-cat/agent-conversations.json
```

PDF tools remain experimental. Keep them disabled if you only want the chat,
context, and web-search features from earlier releases.

## Privacy

Zotero-Cat stores settings and custom context locally in Zotero preferences,
conversation history in a local JSON file, and API keys in Firefox Login
Manager. Content is sent only to the provider and optional search service
configured by the user.

See:

- [Privacy](https://github.com/Zotero-Cat/Zotero-Cat/blob/main/doc/user/PRIVACY.md)
- [隐私说明](https://github.com/Zotero-Cat/Zotero-Cat/blob/main/doc/user/PRIVACY.zh-CN.md)

## Known Limitations

- PDF tools are experimental and off by default.
- Highlight and underline text must be a continuous verbatim span from one PDF
  page; cross-page highlights need separate proposals per page.
- Scanned, encrypted, or OCR-poor PDFs may not provide reliable extractable
  text.
- Web search uses search snippets only; it does not crawl full webpages.
- Token budgeting is approximate.
- Model context length and reasoning-effort options depend on metadata returned
  by the provider.
- Zotero 10 beta support is not enabled yet.
